# 功能需求：需求管理工具链（REQ）

> 版本：v1.0 · 日期：2026-08-25 · 状态：生效
> 定位：需求条目化与追踪的工具链需求；规格见 `../../what/req-mgmt.md`

### FR-REQ-001 需求条目化且机器可读
- 状态: 生效 | 上层: BR-003 | 优先级: P0
- 描述: 需求以带稳定 ID 的结构化文本存于 Git（Sphinx-Needs 或等价物），可导出 JSON。
- 验收: Agent 可经 API/文件读取全部需求条目及其 ID、状态字段。

### FR-REQ-002 需求↔代码↔测试追踪矩阵
- 状态: 生效 | 上层: BR-003 | 优先级: P1
- 描述: 自动生成需求、代码、测试之间的追踪矩阵。
- 验收: 矩阵中每条需求可定位到实现与验证；代码变更可反查受影响需求。

### FR-REQ-003 需求管理界面
- 状态: 生效 | 上层: BR-003 | 优先级: P2
- 描述: OpenProject 提供需求条目、状态、看板、层级的 GUI 管理，经 API 与机器可读层同步。
- 验收: GUI 中的需求变更可同步到 Git 中的条目化需求（或反向）。

# 功能需求：CI/CD 流水线（CI）

> 版本：v1.0 · 日期：2026-08-25 · 状态：生效
> 定位：Jenkins 流水线的功能需求；机制见 `../../how/images-toolchain.md`

### FR-CI-001 push 自动触发流水线
- 状态: 生效 | 上层: UR-003 | 优先级: P0
- 描述: Gitea push/merge 经 Webhook 触发对应 Jenkins 流水线。
- 验收: push 后无需人工操作流水线开始执行，且记录触发来源。

### FR-CI-002 一次性容器内构建
- 状态: 生效 | 上层: UR-002, NFR-005 | 优先级: P0
- 描述: 构建在 Docker inbound agent 一次性容器中执行，环境为版本锁定的工具链镜像。
- 验收: 构建日志显示运行于工具链容器；宿主机无需安装构建依赖。

### FR-CI-003 测试报告统一归档
- 状态: 生效 | 上层: UR-003 | 优先级: P0
- 描述: 测试结果以 Allure 报告聚合归档，可从 Jenkins 查看。
- 验收: 含测试的流水线结束后可打开 Allure 报告。

### FR-CI-004 Jenkins 配置即代码
- 状态: 生效 | 上层: NFR-004 | 优先级: P1
- 描述: Jenkins 全部配置由 JCasC + 插件清单固化进镜像，开箱即用、可重建。
- 验收: 删除容器卷重建后，Jenkins 配置自动恢复。

# ADR-0009 报告落文件卷 + DB 只存元数据

> 日期：2026-08-21 · 状态：已接受
> 关联：how/manager-architecture.md §2.3；需求 FR-MGR-008
> （本篇为文档重构时对原 docs/02 §13.3 决策的追记）

## 背景

Agent 产出的报告是 Markdown 长文本，需要进文档站、知识库与 Git 生态。

## 决策

报告正文落**文件卷**（`reports/`），Postgres 只存元数据与索引。

## 备选方案

| 方案 | 否决原因 |
|------|---------|
| 报告全文存 DB | Markdown 无法直接进入 Git/文档站/Obsidian 生态；大文本撑大 DB 备份 |
| 直接提交到 Git 仓库 | 失去文件系统的简单性；审批前状态用 Git 分支表达过重 |

## 后果

- 正面：报告天然可渲染进文档站、可进 vault 生态。
- 负面：需保证文件卷与 DB 元数据的一致性（Run 失败时的孤儿文件清理）。
- 同步：what/manager.md §数据模型。

# Runbook: Chronicler 账号密码重置

> 版本：v1.0 · 日期：2026-09-27 · 状态：生效
> 适用：Chronicler 宿主终端；Web 操作需已登录的 Chronicler admin 与 OIDC 后端
> 定位：重置已有账号的本地或统一登录密码；不负责组件服务凭据轮换
> 关联：FR-MGR-017；chronicler/app/password_tui.py、chronicler/app/routers/users.py

## 目的

忘记密码或需要为用户重置密码时，通过宿主终端或管理员页面恢复登录。
本地密码与统一登录密码独立，按实际登录方式选择入口。

## 选择入口

| 要重置的密码 | 操作入口 | 生效范围 |
|--------------|----------|----------|
| Chronicler 本地账号密码 | 终端菜单 `3) 重置本地密码` | Chronicler 本地账密登录 |
| OIDC 模式下 admin 的本地应急密码 | 终端菜单 `3) 重置本地密码` | Chronicler 本地账密兜底，不改变统一登录密码 |
| Keycloak 统一登录账号密码 | 终端菜单 `4) 重置统一登录密码`，或 Web「用户」页「重置密码」 | 使用该 Keycloak 账号的统一登录入口 |

OIDC 模式下，普通用户不能用菜单 3 设置本地密码，应使用菜单 4。
菜单 4 设置的是永久密码；Web 重置默认使用临时密码，要求用户下次登录时改密。

## 一、宿主终端操作（忘记 admin 密码时可用）

不需要先登录 Web。操作者需要能够访问该实例的宿主文件和数据库。
使用启动 Chronicler 的同一套环境；若服务设置了 `CHRONICLER_DATA`，终端也必须设置为同一路径，
否则会操作另一个数据库。默认数据库为安装根下 `data/private/chronicler/chronicler.db`。

1. 在真实的交互终端进入仓库根目录，运行密码菜单。

   Windows PowerShell（本机源码运行环境）：

   ```powershell
   Set-Location C:\D\code\AI-CICD-System
   .\chronicler\.venv-win\Scripts\python.exe -m chronicler passwords
   ```

   WSL/Linux（先进入仓库根目录）：

   ```bash
   chronicler/.venv/bin/python -m chronicler passwords
   ```

   已安装的 sealed 发行版，在安装目录执行 Windows 的 `.\chronicler.exe passwords`，
   或 Linux/macOS 的 `./chronicler passwords`。

2. 预期看到：

   ```text
   Chronicler 本地密码管理
   1) 列出账号
   2) 创建初始 admin
   3) 重置本地密码
   4) 重置统一登录密码
   q) 退出
   ```

3. 可先输入 `1` 查看用户名、角色和类型。这里列出的是 Chronicler 已建档账号，
   不包含所有 Keycloak 用户；尚未登录过 Chronicler 的统一登录用户，可直接在菜单 4 输入其用户名。
4. 按上表输入 `3` 或 `4`，再输入用户名。菜单 3 要求账号已存在。
   菜单 4 要求身份组件提供 `hooks/users.py`，组件运行正常且其管理凭据可用；
   默认底座由 Keycloak 提供，凭据引用秘密库时还需秘密库可解锁。
5. 按提示输入新密码，再输入一次确认。密码至少 6 位，输入时不回显。
   两次输入不一致或长度不足时不会修改密码，可重新选择菜单操作。
6. 出现 `已重置本地密码：<用户名>` 或 `已重置统一登录密码：<用户名>` 后，输入 `q` 退出。
   密码修改后无需重启 Chronicler。

菜单 2 用于创建不存在的本地 admin；已有同名账号请使用菜单 3 重置。
不要将密码放到命令参数或脚本中，也不要通过管道传入菜单；程序要求 stdin/stdout 均为交互终端。

## 二、Web 管理员重置统一登录密码

1. 使用 Chronicler admin 账号登录，进入「用户」标签页。
2. 找到目标用户，点击该行「重置密码」。此按钮仅在 OIDC 后端显示；
   表格仅包含已在 Chronicler 建档的账号，未列出的 Keycloak 用户可使用上述终端菜单 4。
3. 输入至少 6 位的新密码。保留默认勾选的「临时密码（用户下次登录须改密，推荐）」，
   或取消勾选以设置永久密码。
4. 点击「重置」，再在确认框点击「确认重置」。预期出现 `已重置 <用户名> 的密码`。
5. 将临时密码安全交给本人，由本人完成下次登录与改密。

Web 的这个操作重置的是 Keycloak 统一登录密码；admin 的本地应急密码请使用终端菜单 3。
本地后端没有 Web 重置按钮，可直接使用终端菜单 3，保留原账号和关联记录。

## 验证

先退出原登录会话，或打开新的浏览器无痕窗口，再按对应方式登录：

- 本地密码：访问 `http://127.0.0.1:8600`，用本地账密表单输入用户名和新密码。
  OIDC 模式下先点击「本地应急账号登录」展开表单，此入口仅允许 admin 应急登录。
- 统一登录密码：在 Chronicler 登录页选择「通过 Keycloak 统一登录」，
  用新密码完成认证；临时密码应出现改密提示，完成后能进入 Chronicler。

以新密码成功登录为最终验证。已有会话可能继续有效，不能用仍保持登录的页面验证新密码。
如使用自定义端口或域名，请换成该实例实际入口。

## 回滚

旧密码不能从哈希中恢复。误设或忘记新密码时，通过同一入口再次重置；
密码重置不需要删除账号，也不需要重新初始化实例。

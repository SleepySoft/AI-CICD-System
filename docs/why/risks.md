# 风险与对策

> 版本：v1.0 · 日期：2026-08-25 · 状态：生效
> 定位：项目级风险登记册；风险变化（新增/消退/兑现）时更新本文件
> 关联需求：NFR-001、NFR-003、NFR-007

| 风险 | 影响 | 对策 | 状态 |
|------|------|------|------|
| Anaconda 类授权再变 | 组件被迫替换、法律风险 | 关键组件固定选 OSI 许可；安装器内置 license 清单检查（规划） | 开放 |
| Android 构建拖垮整机 | 整机不可用 | 独立 profile + 独立构建节点选项 + compose 资源限额 | 已缓解（profile 隔离） |
| Keycloak 配置复杂劝退 | 部署失败率高 | 预置 realm 自动导入；保留"跳过 SSO 用内置账号"降级项（规划） | 已缓解（realm 预置） |
| Agent API 费用失控 | 运营成本 | 本地 Ollama 小模型兜底；报告类任务支持本地模型（NFR-007） | 开放 |
| 组件过多难维护 | 运维负担 | profile 按需启用；每组件健康检查 + Uptime Kuma；镜像版本锁定 | 已缓解 |
| WSL2 空闲回收导致容器重启 | 服务中断 | `.wslconfig` 设 `vmIdleTimeout=-1`（本机实测，见 ../../AGENTS.md） | 已缓解 |

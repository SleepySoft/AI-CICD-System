# Project Shadow

这是源项目的认知镜像仓，用于维护当前需求、设计、运维事实、重要演化、已验证经验、认知缺口和维护记录。它不复制源代码。

- 治理规范：[SKILL.md](SKILL.md)
- 机器状态：[.cognitive-state.yaml](.cognitive-state.yaml)
- 资产模板：`templates/`

当前状态以 `docs/` 为准；演化过程以 `evolution/` 为准；实践经验以 `know-how/` 为准；当前问题以 `assessments/current.md` 为准；每次维护过程以 `runs/` 为准。

首次认知维护完成前，本仓只包含初始化骨架。Project Cognitive Maintainer 必须先读取 `SKILL.md`，再根据证据创建或更新资产。
